첨부한 최신 사이트 ZIP과 새 강의자료를 기준으로 ‘가족관계’ 학습 자료실을 업데이트해 줘.

새 자료의 주차: [입력]
원본 강의 PDF: [첨부]
과제·활동 안내문: [있으면 첨부]
최신 사이트 ZIP: [반드시 첨부]

1. 사이트 이름은 ‘가족관계’로 유지한다. 희망 GitHub 사용자 사이트 주소는 nohyoon20050624.github.io이다. 실제 게시·계정 상태는 확인 없이 완료했다고 말하지 않는다.
2. 기존 주차의 원문·해석·요약·퀴즈를 보존하고 새 주차를 추가한다.
3. 주차별 탭은 정확히 ‘원문 내용 / 한글 해석 / 내용 요약 / 퀴즈’로 구성한다.
4. 원문은 PDF의 실제 슬라이드·표·이미지를 페이지별로 확인할 수 있게 한다.
5. 한글 해석은 원문의 모든 페이지를 순서대로 반영한다. 과도하게 요약하거나 사실을 덧붙이지 않는다.
6. 내용 요약·용어 풀이에는 실제 원문 페이지 링크를 넣는다. 원문 내용과 학습 보조 설명을 구분한다.
7. 퀴즈는 핵심 개념·비교·사례 적용을 확인하는 객관식 및 OX로 구성한다. 정답·해설·근거 페이지를 넣으며, 원문에 없는 정보를 정답 근거로 쓰지 않는다.
8. 같은 주차의 과제나 수업 활동은 activities에 연결하고, 질문 원문·해석·요구 조건을 구분한다. 원문에 없는 기한·분량·제출 방식을 만들어 내지 않는다.
9. 운영자만 게시한다. 방문자 로그인·개인정보 입력·업로드·댓글·개인 메모·방문자 추적·영구 기록 저장 기능을 넣지 않는다. 퀴즈는 브라우저에서만 채점하고 서버로 전송하지 않는다.
10. 원문 페이지 수, 한글 페이지 수, 퀴즈 정답·해설, 원문 링크를 검증한다. 모바일 화면과 데스크톱 화면에서 깨짐·오류·외부 요청 여부를 확인한다.
11. 결과는 업데이트된 게시용 ZIP과 단일 HTML 미리보기로 제공한다. 코드 파일이 완성된 것과 인터넷 게시 완료를 명확히 구분한다.
